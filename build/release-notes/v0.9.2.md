## BV Mudrana 0.9.2

Page layout for Kannada, Sanskrit and English, that opens your PageMaker books.

**Which file do I download?**
- **BV-Mudrana-Setup-0.9.2.exe**: first install on a computer (about 115 MB).
- **BV-Mudrana-Update-0.9.2.exe**: you already have BV Mudrana 0.8 or 0.9. Installs over it and keeps your settings (about 4 MB).

Windows 10 or 11, 64-bit. PageMaker 7 is optional (only to save .pmd files and open PageMaker 4). InDesign is optional (only for .indd; IDML works without it).

### Fixed in 0.9.2
- PageMaker 5 files no longer come out mixed up or overlapped: text blocks start with exactly the text they had in PageMaker and are threaded in PageMaker's order.
- Tab stops are read, so tables and running heads line up.
- Rules and boxes are straight and in place; letter spacing is no longer stretched.
- Automatic hyphenation and PageMaker-style word spacing, so lines break closer to the original.
- Nalanda IAST accents (ū, ṛ, ṃ and others) convert correctly to BV Nanda.

### New in 0.9.2
- Praja Unicode, BV Nanda, BV Chitkala and BV Matanga are bundled and installed in Windows for your account on first start (Utilities > Install Brahmavidya Fonts in Windows to do it again).

Source code is in this repository. Product page: https://brahmavidya.co.in/bv-mudrana/
